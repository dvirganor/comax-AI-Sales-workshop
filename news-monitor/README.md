# ניטור חדשות: ERP, קופות ורשתות קמעונאות

המערכת סורקת מקורות חדשות **כל שעה בין 08:00 ל-18:00, בימים א'-ה'**. היא מאתרת ידיעות עסקיות וידיעות סייבר על:
- **בתי תוכנה, ERP וקופות:** ווריפון, פריוריטי, SAP, אופנת תוכנה (OTECH), ניאקס, אביב קופות, ביקום, טאביט, NCR, ריטליקס, אוטוסופט, דוקופוינט, שופיפיי.
- **רשתות קמעונאות:** כ-60 רשתות מזון, פארם, אופנה, בית וחשמל, וגם ידיעות כלליות על הענף.

הפלט מגיע בשתי דרכים:
1. **דוח HTML מקומי** (`output\report.html`). כותרות עם קישור למקור, מסודרות לפי יום, עם סינון לפי תחום, סוג (סייבר / עסקה) וחיפוש חופשי. הדף מתרענן לבד כל 15 דקות, ויש בו כפתור **🔄 רענן עכשיו** שמפעיל סריקה מיידית ומציג את התוצאות בסיומה.
2. **הודעה בבוט טלגרם פרטי.** בכל סריקה נשלחות רק הכותרות החדשות.

## מקורות

| מקור | אופן הקריאה |
|---|---|
| Google News (בעברית, ישראל) | חיפוש לפי שמות החברות. מכסה את גלובס, דה מרקר, כלכליסט, ynet, N12, ice ואתרים נוספים |
| ynet, גלובס, כלכליסט, דה מרקר, N12, ice, Geektime | פידים של RSS |
| "חדשות הסייבר - ארז דסה": האתר [cybersecurityil.co.il](https://cybersecurityil.co.il/) | פיד RSS ‏(`/feed/`) |
| טלגרם: "חדשות הסייבר - ארז דסה" ([t.me/CyberSecurityIL](https://t.me/CyberSecurityIL)) | תצוגת הרשת הציבורית `t.me/s/CyberSecurityIL`, בלי התחברות |
| ransomware.live | קורבנות כופרה ישראליים שפורסמו באתרי הדלפה |

כל ידיעה עוברת שלבים אלה:
- **זיהוי חברה:** כולל תחיליות בעברית, למשל "בשופרסל" או "ל-SAP".
- **תיוג:** `סייבר` או `עסקה / שינוי מבני` (רכישה, מיזוג, סניפים, הנפקה וכו').
- **איחוד מקורות:** אותה ידיעה מכמה אתרים מוצגת פעם אחת, והקישורים למקורות הנוספים מופיעים מתחת לכותרת ("🔗 גם ב: ynet · כלכליסט"). ידיעה שכבר הוצגה לא חוזרת, אבל אם היא מתפרסמת אחר כך באתר נוסף, הקישור נוסף לדוח. ידיעות מאוחדות כשהכותרת זהה.

## התקנה (Windows, פעם אחת)

1. **התקנת Python 3.10 ומעלה** מ-https://www.python.org/downloads/. במסך ההתקנה סמן את **Add python.exe to PATH**.
2. **הורדת הפרויקט** (התיקייה `news-monitor`) למחשב.
3. **הרצת ההתקנה:** לחיצה כפולה על `scripts\install.bat`. ההתקנה יוצרת סביבה וירטואלית, מתקינה את התלויות ורושמת שתי משימות ב-Task Scheduler: `NewsMonitor` (הסריקה השעתית) ו-`NewsMonitorServer` (שרת מקומי לדוח ולכפתור הרענון, עולה אוטומטית בכניסה למחשב).
4. **הגדרת בוט טלגרם:**
   1. בטלגרם, פתח את **@BotFather**, שלח `/newbot` ובחר שם. תקבל טוקן.
   2. הדבק את הטוקן ב-`secrets.yaml`, בשדה `bot_token`.
   3. שלח לבוט החדש הודעה כלשהי, למשל "שלום".
   4. הרץ את `scripts\telegram_chat_id.bat` והעתק את המספר שמופיע לשדה `chat_id` ב-`secrets.yaml`.
   5. הרץ את `scripts\telegram_test.bat`. אמורה להגיע הודעת בדיקה.
5. **בדיקת המקורות:** הרץ את `scripts\check_sources.bat`. הפקודה מציגה כמה פריטים התקבלו מכל מקור. ✗ ליד מקור מסמן שהוא נכשל (ראה "פתרון בעיות").
6. **סריקה ראשונה:** הרץ את `scripts\run_now.bat`. בסיומה הדוח נפתח בדפדפן.

> בסריקה הראשונה הבוט לא שולח את כל מה שנמצא, אלא הודעת סיכום אחת. מהסריקה הבאה נשלחות רק ידיעות חדשות.

## שימוש יומיומי

| קובץ | מה הוא עושה |
|---|---|
| `scripts\open_report.bat` | פותח את הדוח בכתובת http://127.0.0.1:8765, עם כפתור הרענון |
| `scripts\run_now.bat` | סריקה מיידית, גם מחוץ לשעות הפעילות |
| `scripts\check_sources.bat` | בדיקת תקינות של כל המקורות |
| `scripts\unregister_task.ps1` | הסרת המשימות המתוזמנות |
| `logs\monitor.log` | יומן ריצות ושגיאות |

## התאמה אישית (`config.yaml`)

- **הוספה או הסרה של חברה:** תחת `groups`. לכל חברה מגדירים `name` (שם לתצוגה) ו-`aliases` (כינויים בעברית ובאנגלית).
- **שם בעל משמעות נוספת** (למשל "גולף", "פוקס", "באג"): מוסיפים `require_context: true`. אז הידיעה תיספר רק אם מופיעה בה גם מילת הקשר מתוך `context_words`, כמו "רשת", "סניפים" או "חנויות".
- **מילות תיוג:** תחת `tags`.
- **שעות וימים:** תחת `schedule`. אחרי שינוי מריצים את `scripts\register_task.ps1` מחדש.
- **ידיעות "סייבר כללי" בבוט:** כברירת מחדל, פוסטים מערוץ הסייבר ומ-ransomware.live שלא מוזכרת בהם חברה מהרשימה מופיעים רק בדוח. כדי לקבל אותם גם בבוט, מגדירים `send_general_cyber: true`.

## כפתור "רענן עכשיו"

הכפתור עובד כשהדוח פתוח דרך השרת המקומי (`open_report.bat`, או בדפדפן: http://127.0.0.1:8765). השרת זמין רק מהמחשב שלך.
- **מה קורה בלחיצה:** מתבצעת סריקה מלאה, גם מחוץ לשעות הפעילות. בסיומה הדף נטען מחדש עם הידיעות החדשות. ידיעות חדשות נשלחות גם לבוט, כמו בסריקה רגילה.
- **סריקה שכבר רצה:** אם בזמן הלחיצה כבר רצה סריקה מתוזמנת, הכפתור ממתין לסיומה ולא מפעיל סריקה נוספת.
- **פתיחה ישירה של הקובץ:** אם `report.html` נפתח ישירות מהתיקייה, הכפתור מציג הנחיה לפתוח את הדוח דרך השרת.
- **שינוי פורט:** את הפורט (8765) אפשר לשנות ב-`config.yaml` תחת `server`. במקרה כזה צריך לעדכן גם את `open_report.bat`.

## מגבלות

- **המחשב צריך להיות דלוק ומחובר למשתמש.** אם הוא היה במצב שינה בזמן הריצה, הסריקה תרוץ ברגע שהוא יתעורר.
- **דה מרקר וכלכליסט חסומים בחומת תשלום.** הכותרת והקישור מתקבלים, הכתבה עצמה נפתחת לפי המנוי שלך.
- **מקור עלול להפסיק לעבוד.** אתרים משנים לפעמים כתובות RSS או חוסמים בוטים. מקור שנכשל מופיע באזהרה בראש הדוח וביומן, ו-Google News ממשיך לכסות את אותו אתר.
- **זיהוי לפי מילות מפתח.** יהיה קצת רעש, וידיעות שלא מוזכר בהן שם החברה יתפספסו. אפשר לשפר את התוצאות דרך הכינויים ו-`require_context`.

## פתרון בעיות

- **מקור RSS נכשל (✗):** פתח את אתר המקור, חפש את סמל ה-RSS ועדכן את הכתובת ב-`config.yaml`. אפשר גם למחוק את המקור, כי Google News מכסה אותו.
- **טלגרם: "לא נמצאו פוסטים":** בדוק את שם הערוץ ב-`handle`. אם הערוץ לא מאפשר תצוגה ציבורית, נדרש חיבור דרך API של טלגרם (Telethon). אפשר להוסיף את זה בהמשך.
- **לא מגיעות הודעות לבוט:** הרץ את `telegram_test.bat` וחפש שגיאות ב-`logs\monitor.log`.
